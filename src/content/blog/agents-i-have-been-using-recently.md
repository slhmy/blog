Some notes on my recent preferences and impressions after using different kinds of agents.

# Participants

## GPT & Codex

I subscribe to the $200 GPT Pro plan and use it as my main model. There was a period when I was extremely frustrated by GPT's intelligence problems, but after cooling down a bit, I realized that it has actually remained consistently useful. In a sense, I even think GPT is a relatively honest model: it does cut corners, but partly because of that, it is less likely to overcomplicate a problem. By contrast, Opus sometimes expands a problem beyond the point where I can comfortably control it.

Codex itself is not as powerful as Claude, but it has most of the features I need. If a project is configured properly, the actual experience is not bad at all.

There is not much to complain about in the software ecosystem either. The Codex desktop app is focused enough, and I sometimes use Codex Mobile to access the Mac Mini at home and run tasks there. Overall, it is quite convenient.

The only thing that bothers me is that Codex must use OpenAI's latest `/responses` API. If you want to connect most other models, you usually need to run some local conversion tools. But this is not entirely Codex's fault. It is just that, for now, not many model providers seem interested in following this API redesign.

## Third-Party Models & Claude

For policy reasons, I face a high risk of account bans when using official services, so I have not been able to fully experience Claude's ecosystem. But almost everyone knows about Claude Code and will use it, because it is genuinely good.

Personally, I currently prefer connecting DeepSeek V4, especially for reviews, where it feels quite fast. GLM 5.2 is also capable, but it is simply too slow.

## OpenCode & OpenChamber

If you want higher flexibility and your usage is not especially heavy, OpenCode is a good option.

My positive impression of OpenCode mainly comes from OpenChamber. It provides almost all the features I use in the Codex desktop app, and it makes it easy for me to explore and customize OpenCode through a modern UI.

I think OpenCode is better suited to the small group of people who clearly know they need customization. It has an excellent TUI with plenty of information, but for me, it is still not as ready to use out of the box as GPT/Codex or Claude.

# Summary

In my view, coding agents are essentially an emerging workflow. They allow people to control the development process through natural language, which gives more people access to the convenience of programming.

That said, I would also argue that over trusting agents, or using them out of the box without thinking, is not a silver bullet for every scenario. They can certainly make things more convenient, but they can also drag people who do not understand what is happening into a deep pit. I will explain the reasons behind this in another article.

It is not hard to see that many advanced features require additional project-level customization. So instead of repeatedly worrying about which tool to use, it may be more important to first figure out how to build a smoother development sequence. The tools themselves matter, of course, but what ultimately determines the upper limit of the experience is often how you place them into your own workflow.
